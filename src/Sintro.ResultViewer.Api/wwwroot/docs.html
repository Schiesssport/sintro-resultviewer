Collections, paging and sync

Lists are paged by cursor, not by offset: the installation keeps writing new records and prunes old ones, so an offset would skip or repeat entries. Pass nextCursor back as cursor; hasMore says whether there is more. To sync with event software: request state=finished&order=asc with from/to set to the shooting days, store the last nextCursor and pass it again next time, which returns exactly the passes of those days finished since.
